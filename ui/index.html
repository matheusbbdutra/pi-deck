    Sobre
  

  

    

    
O sightdeck é um cliente desktop para o pi — ele não instala nem
    atualiza o pi sozinho: os botões de atualização chamam pi update.

  






  

    
    Tema
    
    
    
    
  

  

    
    
cole um JSON de tokens (--bg, --accent, …) e clique em aplicar

    
Só as 46 chaves do tema valem; valor precisa ser #rgb, #rrggbb,
    #rrggbbaa, rgb(), rgba(), hsl() ou hsla() —
    o resto é ignorado. O tema fica em localStorage['theme'] até resetar.
